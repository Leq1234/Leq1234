# 黑马记账 App - 产品需求文档（PRD）

## 1. 产品概述

### 1.1 产品名称
**黑马记账**

### 1.2 产品定位
一款面向个人用户的轻量级 H5 记账应用，帮助用户轻松记录日常收支、管理预算、分析消费习惯。采用活泼可爱的设计风格，让记账不再枯燥。

### 1.3 目标平台
- H5 网页应用（移动端优先，兼容桌面端）
- 可通过浏览器直接访问，无需下载安装

### 1.4 目标用户
| 用户画像 | 描述 |
|---------|------|
| 年龄段 | 18-35 岁 |
| 身份 | 学生、上班族、自由职业者 |
| 需求 | 简单高效的个人财务管理 |
| 使用场景 | 日常消费后随手记一笔，月末查看消费报告 |

## 2. 功能模块

### 2.1 核心功能清单

| 优先级 | 功能模块 | 说明 | 版本 |
|-------|---------|------|------|
| P0 | 收支记录 | 记录每日收入和支出，支持分类 | v1.0 |
| P0 | 数据统计 | 图表展示消费趋势、分类占比 | v1.0 |
| P1 | 预算管理 | 设置月度/年度预算，超支提醒 | v1.0 |
| P1 | 多账本 | 支持创建多个账本 | v1.0 |
| P2 | 账单导入 | 从支付宝/微信导入账单 | v1.5 |

---

### 2.2 功能详细说明

#### 2.2.1 收支记录（P0）

**功能描述：** 用户可以快速记录每一笔收入或支出。

**用户故事：**
- 作为用户，我希望能快速记录一笔支出，以便追踪我的消费。
- 作为用户，我希望能选择消费分类，以便后续分析。
- 作为用户，我希望能添加备注，以便回忆具体消费内容。

**功能要求：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 类型 | 选择 | 是 | 收入/支出 |
| 金额 | 数字 | 是 | 支持两位小数 |
| 分类 | 选择 | 是 | 预设分类+自定义分类 |
| 日期 | 日期 | 是 | 默认当天，可修改 |
| 备注 | 文本 | 否 | 最多 50 字 |
| 账本 | 选择 | 是 | 默认"日常"账本 |

**预设支出分类（带图标）：**
🍔 餐饮、🚌 交通、🛒 购物、🏠 住房、📱 通讯、🎮 娱乐、👔 服饰、💊 医疗、📚 教育、🎁 礼物、💡 生活缴费、✈️ 旅行、🐱 宠物、🔧 其他

**预设收入分类（带图标）：**
💰 工资、💵 兼职、🎁 红包、📈 投资收益、💸 报销、🔧 其他

**交互流程：**
1. 用户点击首页底部"+"按钮
2. 选择"支出"或"收入"
3. 通过数字键盘输入金额
4. 选择分类图标
5. （可选）添加备注、修改日期、选择账本
6. 点击"保存"完成记录

---

#### 2.2.2 数据统计（P0）

**功能描述：** 通过可视化图表展示用户的消费数据。

**统计维度：**
- **周报**：最近 7 天每日收支折线图
- **月报**：当月收支总览、分类占比饼图、每日趋势柱状图
- **年报**：12 个月收支趋势、年度分类排行

**页面内容：**

| 区域 | 内容 | 图表类型 |
|------|------|---------|
| 顶部概览 | 总收入、总支出、结余 | 数字卡片 |
| 趋势图 | 按时间维度的收支变化 | 折线图/柱状图 |
| 分类占比 | 各分类消费比例 | 环形饼图 |
| 排行榜 | 消费最高的前 5 个分类 | 列表排行 |

---

#### 2.2.3 预算管理（P1）

**功能描述：** 用户可设置月度总预算和各分类预算。

**功能要求：**
- 设置每月总预算金额
- 为各消费分类设置单独预算（可选）
- 预算进度可视化（进度条）
- 消费达到预算 80% 时提示预警
- 超出预算时弹出提醒

**预算状态：**
| 状态 | 条件 | 颜色 |
|------|------|------|
| 健康 | 已用 < 50% | 绿色 |
| 注意 | 50% ≤ 已用 < 80% | 橙色 |
| 预警 | 80% ≤ 已用 < 100% | 红色 |
| 超支 | 已用 ≥ 100% | 深红色 |

---

#### 2.2.4 多账本（P1）

**功能描述：** 支持创建多个独立账本，适应不同场景。

**功能要求：**
- 默认创建"日常"账本
- 支持新建账本（名称 + 图标 + 颜色）
- 账本之间数据独立
- 支持切换当前活跃账本
- 支持账本归档和删除（删除需二次确认）

**预设账本模板：**
- 📒 日常记账
- ✈️ 旅行账本
- 🏠 家庭开支
- 📋 项目专用

---

#### 2.2.5 账单导入（P2 - v1.5）

**功能描述：** 支持从主流支付平台导入消费记录。

**支持格式：**
- 支付宝账单 CSV 文件
- 微信支付账单 CSV 文件

**导入流程：**
1. 用户从支付宝/微信导出账单文件
2. 在 App 中选择"导入账单"
3. 上传 CSV 文件
4. 系统自动解析并匹配分类
5. 用户确认后批量导入

## 4. 数据存储

### 4.1 存储方案
- **本地存储**：使用浏览器 LocalStorage / IndexedDB
- **无需后端服务器**，所有数据存储在用户本地
- 后续版本可扩展云同步功能

### 4.2 核心数据模型

#### 账单记录（Record）
```
{
  id: string,           // 唯一标识
  type: "income" | "expense",  // 类型
  amount: number,        // 金额（分为单位存储）
  categoryId: string,    // 分类ID
  bookId: string,        // 账本ID
  date: string,          // 日期 YYYY-MM-DD
  note: string,          // 备注
  createdAt: timestamp,  // 创建时间
  updatedAt: timestamp   // 更新时间
}
```

#### 分类（Category）
```
{
  id: string,
  name: string,          // 分类名称
  icon: string,          // 图标
  type: "income" | "expense",
  isCustom: boolean,     // 是否自定义
  sort: number           // 排序
}
```

#### 账本（Book）
```
{
  id: string,
  name: string,          // 账本名称
  icon: string,          // 图标
  color: string,         // 主题色
  isArchived: boolean,   // 是否归档
  createdAt: timestamp
}
```

#### 预算（Budget）
```
{
  id: string,
  bookId: string,        // 关联账本
  month: string,         // 月份 YYYY-MM
  totalAmount: number,   // 总预算金额
  categoryBudgets: [     // 分类预算
    { categoryId: string, amount: number }
  ]
}
```

## 5. 非功能性需求

| 维度 | 要求 |
|------|------|
| 性能 | 首屏加载 < 2 秒，操作响应 < 200ms |
| 兼容性 | Chrome 80+、Safari 13+、微信内置浏览器 |
| 响应式 | 移动端优先，适配 320px - 1920px 屏幕 |
| 数据安全 | 本地加密存储敏感数据 |
| 离线支持 | 支持 PWA，离线可正常使用 |
| 无障碍 | 支持基本的 ARIA 标签 |
