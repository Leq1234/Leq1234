# 黑马记账 App - UI 设计规范

## 1. 设计理念

### 1.1 设计原则
- **轻松愉快**：活泼可爱的视觉风格，让记账变成一件有趣的事
- **简洁高效**：减少操作步骤，核心流程 3 步内完成
- **信息清晰**：数据展示层次分明，关键信息一目了然
- **一致性**：组件风格统一，交互方式一致

### 1.2 设计风格关键词
`活泼` `可爱` `圆润` `多彩` `友好`

## 8. 动画与过渡

### 8.1 基础过渡

```css
/* 通用过渡 */
--transition-fast: 150ms ease;
--transition-normal: 250ms ease;
--transition-slow: 350ms ease;

/* 弹性过渡（活泼感） */
--transition-bounce: 400ms cubic-bezier(0.34, 1.56, 0.64, 1);
```

### 8.2 动画场景

| 场景 | 动画 | 时长 |
|------|------|------|
| 页面切换 | 左右滑动 | 300ms |
| 弹窗出现 | 从底部弹出 + 遮罩淡入 | 300ms |
| 记账成功 | 对勾 + 缩放弹性动画 | 500ms |
| 数字变化 | 数字滚动动画 | 400ms |
| 列表加载 | 逐项从下方淡入 | 200ms/项 |
| 按钮点击 | 缩放 0.95 → 1.0 | 150ms |
| "+"按钮 | 旋转 45° 变为 "×" 关闭 | 250ms |

## 10. 响应式适配

### 10.1 断点

| 断点 | 宽度 | 布局调整 |
|------|------|---------|
| 小屏手机 | < 375px | 缩小间距，4 列分类网格 |
| 标准手机 | 375px - 428px | 标准布局，5 列分类网格 |
| 大屏手机 | 428px - 768px | 适当放大间距 |
| 平板/桌面 | > 768px | 居中显示，最大宽度 480px |

### 10.2 桌面端适配
```css
/* 桌面端居中 + 手机壳效果 */
@media (min-width: 768px) {
  .app-container {
    max-width: 480px;
    margin: 0 auto;
    box-shadow: 0 0 40px rgba(0, 0, 0, 0.1);
    min-height: 100vh;
  }
}
```

## 11. 空状态与异常

### 11.1 空状态设计
每个空状态包含：可爱插画 + 文字说明 + 操作引导

| 场景 | 插画 | 文字 | 按钮 |
|------|------|------|------|
| 无记录 | 小猫记账插画 | "还没有记录哦~" | "记一笔" |
| 无预算 | 存钱罐插画 | "设个预算管管钱~" | "设置预算" |
| 无账本 | 笔记本插画 | "创建你的第一个账本" | "新建账本" |

### 11.2 加载状态
- 骨架屏（Skeleton）替代 loading 菊花
- 列表项使用灰色占位块闪烁效果
